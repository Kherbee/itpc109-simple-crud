
# ITPC 109 Simple CRUD Application

A simple Student Records Management web application
that allows users to add, view, edit, and delete
student records.

## Technologies

- PHP
- MySQL
- Apache
- Docker
- Git / GitHub

## Run

```bash
docker compose up -d --build
```

## Application

http://localhost:8080

## phpMyAdmin

http://localhost:8081

## Stop

```bash
docker compose down
```
